# 咪咪日常｜寵物成長與生活照護

這是一個可以直接在本機或 Vercel 執行的寵物紀錄網站。建立與編輯寵物、記錄體重和每日生活、瀏覽相簿時間軸、依月份篩選、查看成長曲線，以及匯出／匯入 JSON 備份都已在前端實作，不需要 PostgreSQL、API 金鑰或環境變數。

## 資料儲存方式

本版本將資料存放在瀏覽器 `localStorage`，因此新增紀錄不會呼叫伺服器 API，也不依賴 Vercel 的暫存磁碟。資料會留在目前這個瀏覽器和裝置；清除瀏覽器網站資料、換瀏覽器或換裝置時不會自動同步。請定期使用頁面上的「下載備份」保存 JSON，再於其他瀏覽器使用「匯入備份」。匯入會以備份內容取代目前資料。

相片／影片欄位接受 HTTPS 雲端媒體網址。檔案本身不會上傳或放進瀏覽器資料；請使用你已選擇的雲端相簿／物件儲存服務，並貼上可存取的連結。

## 本機啟動

需要 Node.js 18.17 或更新版本：

```sh
npm install
npm run dev
```

開啟 `http://localhost:3000`。不需要複製 `.env.example`，也不需要設定資料庫。

## 建置與型別檢查

```sh
npm run typecheck
npm run build
```

## GitHub 與 Vercel

專案已連結至 `https://github.com/xaiojiejie0524-byte/petlive.git` 的 `main` 分支。推送更新後，Vercel 會依專案設定自動部署。框架使用 Next.js，Vercel 通常會自動偵測；本專案不需要 `DATABASE_URL` 或 `PG_SSL`。部署完成後開啟網站即可新增資料。

## 功能

- 寵物檔案：建立與編輯名稱、物種、品種、生日、體重單位。
- 成長紀錄：新增體重與備註，以互動式折線圖檢視。
- 生活日誌／成長相簿：日期、文字、標籤、飲食、飲水、排泄、活動與 HTTPS 媒體連結。
- 時間瀏覽：依寵物與月份篩選歷史資料。
- 照護小知識：按物種、生命階段和情境顯示提醒。
- JSON 備份：下載目前所有寵物與紀錄，或在另一台裝置匯入。

照護知識只提供一般生活資訊，不能取代獸醫診斷；有異常時請洽獸醫師。
